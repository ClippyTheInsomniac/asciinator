ASCIInator это довольно идиотская тулза, которую я делал для курсового проекта в колледже (ИИ использовался, в основном для кода на фреймворке QT ибо мне было впадлу и для комментариев, по той же причине). Позволяет преобразовывать jpg, jpeg и png пикчи в ASCII арт и сохранять как в виде текста так и в виде изображения.
